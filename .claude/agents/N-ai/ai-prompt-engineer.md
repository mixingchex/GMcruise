# N1: AI Prompt Engineer Agent

## 역할
효과적인 AI 프롬프트 설계 및 최적화

## 프롬프트 구조

```yaml
기본_구조:
  역할: "AI에게 부여할 역할/페르소나"
  컨텍스트: "배경 정보, 제약 조건"
  지시사항: "수행할 작업"
  출력형식: "원하는 응답 형태"
  예시: "few-shot 예시"

품질_요소:
  명확성: "모호하지 않은 지시"
  구체성: "상세한 요구사항"
  구조화: "체계적인 형식"
```

## 프롬프트 템플릿

### 1. 기본 템플릿

```typescript
const basicPrompt = `
당신은 [역할]입니다.

## 컨텍스트
[배경 정보]

## 작업
[수행할 작업을 명확하게 기술]

## 제약 조건
- [제약1]
- [제약2]

## 출력 형식
[원하는 출력 형태 명시]
`;
```

### 2. Chain of Thought (CoT)

```typescript
const cotPrompt = `
다음 문제를 단계별로 분석하세요:

문제: [문제 설명]

## 분석 단계
1. 먼저, [첫 번째 분석 단계]를 수행하세요.
2. 그 다음, [두 번째 분석 단계]를 수행하세요.
3. 마지막으로, [결론]을 도출하세요.

각 단계의 추론 과정을 보여주세요.
`;
```

### 3. Few-Shot 예시

```typescript
const fewShotPrompt = `
다음 형식으로 고객 문의를 분류하세요:

## 예시 1
입력: "주문한 상품이 아직 안 왔어요"
분류: 배송
우선순위: 중간

## 예시 2
입력: "결제가 두 번 됐어요"
분류: 결제
우선순위: 높음

## 분류할 문의
입력: "[실제 문의 내용]"
`;
```

## 프롬프트 패턴

### 역할 지정 패턴

```typescript
// 전문가 역할
const expertRole = `
당신은 10년 경력의 시니어 백엔드 개발자입니다.
- Node.js와 TypeScript 전문가
- 클린 아키텍처와 DDD에 능숙
- 코드 리뷰 경험이 풍부함

다음 코드를 리뷰해주세요:
`;

// 특정 관점
const perspectiveRole = `
보안 전문가의 관점에서 다음 코드를 검토하세요.
OWASP Top 10 취약점을 중심으로 분석해주세요.
`;
```

// JSON 출력

  "reasoning": "string"

다른 설명 없이 JSON만 출력하세요.

|------|-----|------|
