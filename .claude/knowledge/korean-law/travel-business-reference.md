# 한국 여행업법 참조 가이드

> 최종 업데이트: 2024년 기준
> 관광진흥법 기반

## 1. 여행업 등록

### 여행업 종류

```yaml
일반여행업:
  업무: "국내외 여행 기획/실시"
  등록: "시/도지사 등록"
  보증보험: "2억원 이상"

국내여행업:
  업무: "국내 여행만 기획/실시"
  등록: "시/도지사 등록"
  보증보험: "1억원 이상"

국외여행업:
  업무: "내국인 국외 송출 전문"
  등록: "시/도지사 등록"
  보증보험: "1억5천만원 이상"
```

### 등록 요건

```yaml
시설:
  - "고정 영업장"
  - "사무시설"

인력:
  - "여행업 등록 시 대표자 적격"

자본금:
  일반여행업: "1억원 이상"
  국내여행업: "3천만원 이상"
  국외여행업: "5천만원 이상"

보증보험:
  - "영업보증보험 가입 필수"
```

## 2. 무등록 영업 제재

### 무등록 여행업 운영 시

```yaml
형사처벌:
  벌금: "2천만원 이하"
  또는
  징역: "2년 이하"

행정처분:
  - "영업 정지"
  - "등록 취소"
```

## 3. 크루즈닷 구조 적법성

### 적법한 구조

```yaml
크루즈닷_역할:
  - "여행업 등록 (필수)" ✓
  - "영업보증보험 가입" ✓
  - "여행상품 기획/판매 주체"
  - "고객과 여행계약 당사자"
  - "여행 관련 책임"

판매원_역할:
  - "크루즈닷의 판매 대리인"
  - "직접 여행업 등록 불필요" ✓
  - "크루즈닷 명의로만 판매"
  - "여행계약 당사자 아님"

적법성_요약:
  - "크루즈닷이 여행업 등록되어 있으면 적법"
  - "판매원은 대리인으로서 활동"
  - "여행 관련 모든 책임은 크루즈닷"
```

### 주의사항

```yaml
판매원이_하면_안_되는_것:
  - "크루즈닷과 무관한 여행상품 독자 판매"
  - "본인 명의로 여행계약 체결"
  - "여행업체인 것처럼 홍보"

판매원이_해도_되는_것:
  - "크루즈닷 상품 홍보/판매"
  - "고객 상담 (크루즈닷 위탁)"
  - "예약 접수 대행"
```

## 4. 여행약관

### 필수 고지 사항

```yaml
계약체결전:
  - "여행 일정"
  - "여행 경비 내역"
  - "취소/환불 규정"
  - "여행사 정보 (등록번호 등)"

계약서_필수_포함:
  - "여행사 상호/대표자"
  - "여행업 등록번호"
  - "영업보증보험 정보"
  - "여행 일정"
  - "요금 내역"
  - "취소/환불 조건"
```

### 표준약관

```yaml
국외여행_표준약관:
  발행: "공정거래위원회"
  내용:
    - "계약의 성립"
    - "여행요금"
    - "계약 해제/변경"
    - "손해배상"

준수: "표준약관과 동일하거나 유리해야 함"
```

## 5. 영업보증보험

### 보험 목적

```yaml
보장내용:
  - "여행사 부도 시 고객 피해 보상"
  - "여행 중 사고 시 보상"

청구권자:
  - "여행 계약을 체결한 고객"
```

### 보험금 지급 사유

```yaml
지급사유:
  - "여행사 폐업/파산"
  - "여행사의 채무불이행"
  - "보험기간 중 발생한 사고"
```

## 6. 크루즈 상품 특수 사항

### 크루즈 여행 특성

```yaml
계약구조:
  - "크루즈 선사 - 여행사 - 고객"
  - "여행사는 선사의 판매 대리점 역할"

책임소재:
  선상사고: "선사 책임 (해사법)"
  여행일정: "여행사 책임"

환불규정:
  - "선사별 상이"
  - "출발일 기준 차등"
  - "명확한 안내 필수"
```
