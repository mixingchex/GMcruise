# 한국 노무법 참조 가이드

> 최종 업데이트: 2024년 기준
> 프리랜서 vs 근로자 구분 중심

## 1. 프리랜서 vs 근로자 판단 기준

### 근로자 판단 요소 (대법원 기준)

```yaml
근로자로_판단되는_경우:
  업무지시:
    - "출퇴근 시간 지정"
    - "업무 내용/방법 지시"
    - "업무 수행 장소 지정"

  전속성:
    - "다른 업체 일 못하게 함"
    - "회사 업무만 전담"

  보수체계:
    - "고정 급여 지급"
    - "근무 시간 기준 보수"

  기타:
    - "복무규정 적용"
    - "징계/인사관리 대상"
    - "4대보험 가입"

프리랜서로_판단되는_경우:
  업무자율:
    - "업무 시간 자유"
    - "업무 방법 자율"
    - "장소 제한 없음"

  독립성:
    - "다른 업체 계약 가능"
    - "스스로 고객 발굴"

  보수체계:
    - "실적 기반 수당"
    - "건별/성과 기준"

  기타:
    - "본인 명의 사업 가능"
    - "직접 비용 부담"
```

### 판매원 지위 판단

```yaml
크루즈가이드_판매원_구조:
  자율성:
    - "언제, 어디서 일할지 본인 결정" ✓
    - "판매 방법 자유" ✓

  전속성:
    - "다른 판매 활동 가능" ✓

  보수:
    - "판매 실적 기반 수당" ✓
    - "고정급 없음" ✓

  결론: "프리랜서(독립사업자)로 판단 가능"
```

## 2. 프리랜서 계약 시 주의사항

### 근로자로 오인되지 않도록

```yaml
피해야_할_것:
  - "출퇴근 시간 지정"
  - "업무 보고 의무 부과"
  - "회의 참석 강제"
  - "고정급 지급"
  - "휴가 승인 절차"
  - "복장 규정 적용"

해야_할_것:
  - "업무 자율성 명시"
  - "성과 기반 보수 명시"
  - "독립 사업자 지위 명시"
  - "다른 업무 가능 명시"
```

### 계약서 권장 문구

```yaml
프리랜서_지위_조항:
  예시: |
    "을(판매원)은 갑(마비즈스쿨)과 독립적인 사업자로서
    위탁 관계에 있으며, 갑의 지휘/감독을 받는
    근로자가 아니다.

    을은 본 계약에 따른 업무 수행의 시간, 장소,
    방법을 자유롭게 결정하며, 갑은 이에 대해
    구체적인 지시를 하지 않는다.

    을은 본 계약 외에 다른 업무 활동을 수행할 수 있다."
```

## 3. 근로자로 판단될 경우 리스크

### 소급 적용 항목

```yaml
4대보험:
  국민연금: "소급 가입 + 과태료"
  건강보험: "소급 가입 + 과태료"
  고용보험: "소급 가입"
  산재보험: "소급 가입"

퇴직금:
  대상: "1년 이상 근무 시"
  계산: "평균임금 30일분 × 근속연수"

기타:
  - "연차수당 소급 지급"
  - "최저임금 차액 지급"
  - "근로기준법 위반 과태료"
```

## 4. 수당 정산 가이드

### 프리랜서 수당 정산

```yaml
정산주기:
  권장: "월 1회"
  지급일: "익월 10일~25일"

정산내역:
  필수포함:
    - "판매 건수/금액"
    - "수당 계산 내역"
    - "원천징수 내역"
    - "실지급액"

증빙:
  - "지급명세서 (연간)"
  - "입금 내역"
```

### 환불 시 수당 처리

```yaml
방법1_미지급:
  조건: "아직 수당 미지급"
  처리: "해당 건 수당 미지급"

방법2_차감:
  조건: "이미 수당 지급됨"
  처리: "다음 정산에서 차감"

방법3_별도청구:
  조건: "차감 불가한 경우"
  처리: "별도 환수 청구"

계약서_명시: "환불 시 수당 처리 방법 반드시 명시"
```

## 5. 4대보험 (프리랜서 선택 가입)

### 가입 방법

```yaml
국민연금:
  가입: "지역가입자로 본인 가입"
  보험료: "소득의 9% (본인 전액 부담)"

건강보험:
  가입: "지역가입자로 본인 가입"
  보험료: "소득/재산 기준 산정"

고용보험:
  가입: "자영업자 가입 가능 (선택)"
  혜택: "실업급여, 출산급여"

산재보험:
  가입: "특수형태근로종사자 가입 가능"
  대상: "일부 업종만 해당"
```
