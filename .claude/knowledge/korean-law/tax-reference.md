# 한국 세무법 참조 가이드

> 최종 업데이트: 2024년 기준
> 법률 변경 시 업데이트 필요

## 1. 원천징수 기본

### 사업소득 원천징수 (3.3%)

```yaml
적용대상:
  - "프리랜서 소득"
  - "인적용역 소득"
  - "판매 수수료/커미션"
  - "강사료, 원고료"

세율:
  소득세: 3%
  지방소득세: 0.3%
  합계: 3.3%

계산예시:
  수당: 1,000,000원
  소득세: 30,000원
  지방소득세: 3,000원
  원천징수_합계: 33,000원
  실수령액: 967,000원
```

### 기타소득 원천징수 (8.8%)

```yaml
적용대상:
  - "일시적/우발적 소득"
  - "사례금"
  - "강연료 (일시적)"

주의:
  - "반복적/계속적 소득은 사업소득으로 분류"
  - "판매원 수당은 대부분 사업소득"
```

## 2. 원천세 신고/납부

### 신고 기한

```yaml
매월_신고:
  기한: "지급월 다음달 10일까지"
  예시: "1월 지급분 → 2월 10일까지"

반기_신고 (선택):
  조건: "상시근로자 20인 미만"
  기한:
    상반기: "7월 10일"
    하반기: "1월 10일"
```

### 신고 방법

```yaml
홈택스:
  경로: "홈택스 > 신고/납부 > 원천세"
  필요서류: "원천징수이행상황신고서"

가산세:
  미신고: "납부세액의 10%"
  미납부: "미납일수 × 0.025%"
```

## 3. 지급명세서

### 제출 의무

```yaml
제출대상:
  - "사업소득 지급자"
  - "기타소득 지급자"

제출기한:
  사업소득: "다음해 2월 말"
  일용근로: "지급월 다음달 말"

제출방법:
  - "홈택스 전자제출"
  - "세무서 서면제출"
```

### 미제출 가산세

```yaml
가산세:
  원칙: "지급금액의 2%"
  한도: "1억원"

감면:
  제출기한_후_1개월_이내: "50% 감면"
  제출기한_후_3개월_이내: "20% 감면"
```

## 4. 사업자 vs 비사업자

### 비사업자 (개인)

```yaml
세금처리:
  - "3.3% 원천징수"
  - "5월 종합소득세 신고 (본인)"

지급자_의무:
  - "원천징수"
  - "지급명세서 제출"
```

### 사업자

```yaml
세금처리:
  - "세금계산서 발행"
  - "부가세 10% 별도"

지급자_의무:
  - "세금계산서 수취"
  - "매입세액 공제 가능"
```

## 5. 크루즈닷 적용 가이드

### 어필리에이트 수당 지급 시

```yaml
개인_판매원:
  1: "수당 확정"
  2: "3.3% 원천징수 계산"
  3: "실수령액 지급"
  4: "원천세 신고/납부 (익월 10일)"
  5: "지급명세서 제출 (익년 2월)"

사업자_판매원:
  1: "수당 확정"
  2: "세금계산서 수취"
  3: "수당 + 부가세 지급"
  4: "부가세 신고 시 매입세액 공제"
```

### 연간 세무 일정

```yaml
매월:
  10일: "전월 원천세 신고/납부"

분기:
  1/4/7/10월_25일: "부가세 신고"

연간:
  2월_말: "지급명세서 제출"
  3월_말: "법인세 신고 (법인)"
  5월_말: "종합소득세 신고 (개인사업자)"
```
