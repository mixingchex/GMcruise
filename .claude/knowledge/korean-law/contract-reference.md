# 한국 계약법 참조 가이드

> 최종 업데이트: 2024년 기준
> 크루즈가이드 비즈니스 구조에 맞춤

## 1. 계약의 기본 요건

### 유효한 계약의 요건

```yaml
필수요건:
  당사자: "계약 체결 능력 (만 19세 이상)"
  의사표시: "자유로운 합의"
  목적: "적법하고 실현 가능한 내용"
  형식: "법정 형식 요구 시 준수"

무효사유:
  - "강박/사기에 의한 계약"
  - "반사회적 내용"
  - "불법 목적"
```

## 2. 3자 구조 계약 (마비즈스쿨-판매원-크루즈닷)

### 계약 관계도

```
┌─────────────────┐
│  마비즈스쿨      │ ← 교육/시스템 제공
│ 원격평생교육원   │
└────────┬────────┘
         │ 교육계약
         ▼
┌─────────────────┐
│   판매원/       │ ← 상품 판매 활동
│   대리점장      │
└────────┬────────┘
         │ 수당약정
         ▼
┌─────────────────┐
│   크루즈닷      │ ← 수당 지급, 여행상품 판매
│    (여행사)     │
└─────────────────┘
```

### 계약 1: 마비즈스쿨 - 판매원 계약

```yaml
계약명: "판매원 위촉 계약서" 또는 "교육 및 시스템 이용 계약서"

필수조항:
  제1조_목적:
    내용: |
      본 계약은 마비즈스쿨 원격평생교육원(이하 '갑')이
      판매원(이하 '을')에게 여행상품 판매 교육 및
      시스템 이용 권한을 부여함에 있어
      필요한 사항을 정함을 목적으로 한다.

  제2조_계약당사자:
    갑: "마비즈스쿨 원격평생교육원"
    을: "판매원 (성명, 주민번호, 연락처)"

  제3조_업무범위:
    내용: |
      을은 갑이 제공하는 교육을 이수한 후,
      갑의 시스템을 통해 크루즈닷(주)의
      여행상품 판매 활동을 수행한다.

  제4조_수당 (중요):
    내용: |
      본 계약에 따른 판매 활동에 대한 수당은
      크루즈닷(주)에서 별도 약정에 따라 지급하며,
      갑은 판매 수당 지급 의무가 없다.

  제5조_이용료:
    내용: |
      을은 갑의 시스템 이용 및 교육에 대한 대가로
      월 [금액]원을 갑에게 납부한다.

  제6조_프리랜서_지위:
    내용: |
      을은 독립적인 사업자로서 활동하며,
      갑의 근로자가 아니다.
      을은 업무 시간, 장소, 방법을 자유롭게 결정한다.

권장조항:
  - "개인정보 처리 동의"
  - "비밀유지 의무"
  - "계약 해지 조건"
  - "분쟁 해결 (관할 법원)"
```

### 계약 2: 크루즈닷 - 판매원 수당 약정

```yaml
계약명: "어필리에이트 수당 약정서"

필수조항:
  제1조_목적:
    내용: |
      본 약정은 크루즈닷(주)(이하 '갑')이
      판매원(이하 '을')에게 여행상품 판매에 따른
      수당을 지급함에 있어 필요한 사항을 정한다.

  제2조_수당_계산:
    내용: |
      수당은 상품별로 개별 정해진 수당 기준에 따라
      계산되며, 상품 상세 페이지에 명시된다.

  제3조_지급시기:
    내용: |
      수당은 매월 [일]일에 지급하며,
      고객의 여행 출발 후 확정된 금액을 기준으로 한다.

  제4조_원천징수:
    내용: |
      갑은 을에게 수당 지급 시 소득세법에 따라
      사업소득 원천징수(3.3%)를 공제한 후 지급한다.

  제5조_환불_처리:
    내용: |
      고객 환불 발생 시, 해당 건에 대한 수당은
      지급되지 않거나 기지급 수당에서 차감한다.
```

## 3. 전자계약 유효성

### 전자서명법 요건

```yaml
유효한_전자계약:
  전자서명: "공인인증서 또는 본인인증 (휴대폰 등)"
  동의절차: "약관 확인 및 동의 기록"
  보관: "원본 파일 5년 이상 보관"

권장사항:
  - "계약 체결 일시 기록"
  - "IP 주소 기록"
  - "동의 체크박스 로그"
```

### 계약서 보관 의무

```yaml
보관기간:
  일반계약: "10년 (민법)"
  세무관련: "5년 (국세기본법)"
  근로관련: "3년 (근로기준법)"

보관방법:
  - "전자문서 원본 보관"
  - "수정 불가능한 형태"
  - "백업 보관"
```

## 4. 분쟁 대비

### 필수 포함 조항

```yaml
관할법원:
  예시: "본 계약에 관한 분쟁은 갑의 주소지를 관할하는 법원을 관할 법원으로 한다."

손해배상:
  예시: "계약 위반 시 상대방에게 발생한 실제 손해를 배상한다."

분쟁해결:
  1단계: "당사자 협의"
  2단계: "조정/중재"
  3단계: "소송"
```
